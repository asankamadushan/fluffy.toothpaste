# desktop-bg-app

Multi-monitor desktop background manager. Set different wallpapers per monitor or stitch one image across all screens.

## Requirements

- Python 3.14+
- [uv](https://docs.astral.sh/uv/)

## Setup

```bash
uv sync
```

## Run

```bash
uv run python src/main.py
```

## Test

```bash
uv run pytest
```

## Lint

```bash
uv run ruff check src
```
